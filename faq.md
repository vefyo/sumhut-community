# Frequently asked questions

## Is sumhut free to open?
The public calculator and food pages can be opened without an account. Community posting and messaging require an account.

## Does every food have vitamins and minerals?
No. Detailed records display the nutrients present in the source. Basic reference records and some source records have fewer fields. Unknown is not zero.

## Is one apple a fixed weight?
No. Size, variety and the chosen source affect the assumed mass. Use grams or measurements when accuracy matters.

## Are all non-food objects measured products?
No. Many entries model material and geometry using stated assumptions.

## Is messaging end-to-end encrypted?
No such guarantee is offered. Account permissions control access, and site moderation and retention rules apply. Consult the site's current privacy information before using community features.

## Can I install it on iPhone?
Open the website in Safari, use Share, then Add to Home Screen. The site supplies Apple-compatible icons.

## Does this repository contain the application source?
This is a product documentation and feedback repository. It does not publish the application implementation.

## Does llms.txt guarantee AI discovery?
No. It provides readable product information and source links; discovery, citations and rankings depend on third parties.
