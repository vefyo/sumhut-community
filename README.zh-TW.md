# sumhut — 所有物體與食物估算，讓生活中的數字更清楚。

依數量、質量和來源份量，估算物體質量、重力、體積及食物營養。

[sumhut.com](https://sumhut.com/) · [Community](https://sumhut.com/community)

## 可以做什麼

- 搜尋物體或食物，例如「5 蘋果」「200 g 米飯」。
- 調整個數、公克、公斤、容器淨質量及可用的 USDA 官方份量。
- 查看質量、已知密度對應的體積，以及單位為牛頓的重力。
- 查看熱量、蛋白質、碳水化合物、脂肪、膳食纖維；詳細 USDA 記錄也提供已收錄的維生素與礦物質。
- 組合多個物品，彙總結果、匯出 CSV、分享計算連結。
- 在討論區發布圖片與影片，使用帳號私訊功能。
- 將 sumhut 加入 iPhone 主畫面，使用獨立圖示開啟。

## 資料與精度

截至 2026 年 10 月，目錄包含 21,710 筆記錄：20 筆原始參考、8,789 筆 USDA SR28 食品、469 筆 Foundation、5,432 筆 FNDDS，以及 7,000 筆非食品估算。非食品包含材料與幾何參數範例，並非全部是實測商品。缺少的營養值表示未知，不代表零。大小、烹調方式、材料與密度都會影響結果；需要準確值時請核對標示或實測。
