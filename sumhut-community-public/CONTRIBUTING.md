# Feedback and contributions

Try the website first and include the exact public URL, language, food or object name, quantity, unit, expected result and observed result in a report. For data corrections, include the source, source identifier and units. Screenshots are useful after removing personal information.

Use the repository issue forms for bugs, data corrections and feature ideas. Documentation translations are welcome. Keep language links in this order: English, Español, Português, 简体中文, 繁體中文.

Never include passwords, access tokens, private messages, personal account details or private screenshots in public issues. This repository does not accept application source or deployment secrets.
